# 04 – Curriculum Mapping (Lehrplan 21 · PER · Piano di studio TI)

## Executive Summary

CubeIT and the micro learning game cover the three informatics competence areas of the module
**"Medien und Informatik" (MI)** in Lehrplan 21. The strongest fit is with **MI.2.3 Informatiksysteme**,
which so far has had little tangible material. In French-speaking Switzerland the matching area is the
PER (Plan d'études romand, MITIC / later Éducation numérique). In Ticino it is the *Piano di studio della
scuola dell'obbligo ticinese*.

> Note: the wording below is paraphrased. The binding source is the official curriculum of the
> canton concerned (e.g. v-ef.lehrplan.ch). Check competence codes and level descriptions before
> submitting.

## Mapping

| LP21 area | Competence (paraphrased) | CubeIT element | Cycle |
|---|---|---|---|
| **MI.2.1 Datenstrukturen** | Represent, structure and evaluate data from their environment | Mission 3 "Binär-Würfel" (binary cubes), LED matrix cube, sensor cube | 2–3 |
| **MI.2.2 Algorithmen** | Analyse simple problems, describe solutions and turn them into programs | Mission 2 "Robo-Cube": sequence, debugging, shortest program, recognising a loop | 2–3 |
| **MI.2.3 Informatiksysteme** | Understand how information-processing systems are built and how they work | Mission 1 + physical cubes: IPO/EVA model, power, interfaces, booting | 2–3 |
| MI.1 Medien | Media use, rights, security | Offline game, no data collection, discussion "why no cloud?" | 2–3 |
| Anwendungskompetenzen | Using devices | Keyboard/mouse, switching on, operating a computer | 1–2 |

## Learning goals of the game (testable)

| Mission | Learning goal: the pupil can … | Evidence in the game |
|---|---|---|
| 1 Bau den Computer (build the computer) | … name the minimum parts of a computer and sort them into input, processing and output | Boot only with power + display + USB, all connected; stars by number of failed attempts |
| 2 Robo-Cube | … write a sequence of instructions, find a mistake (bug) and correct it | Crash message, the program stays in place for debugging, comparison with the shortest solution |
| 3 Binär-Würfel (binary cubes) | … show numbers from 1 to 31 with 5 bits | Five targets; stars by extra clicks |

## Interdisciplinary links

- **Mathematics:** place-value systems (decimal ↔ binary), adding powers of two
- **NMG / NT (science and technology):** electricity (circuit, voltage), magnetism (poles attract and repel)
- **TTG (textile and technical design):** design your own cube shell, 3D print it
